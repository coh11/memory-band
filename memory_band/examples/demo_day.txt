# A scripted day for the Memory Band demo. replay.py sends each line to the server.
# Format:  HH:MM | @action  (passive signals: exactly what band_bridge.py / the phone send)
#          HH:MM | words    (optional speech path, as if Deepgram heard them)
# Actions: @double-tap  band double-tap = "yes, I did it / I'm fine"
#          @fall        band felt a fall
#          @leave       phone's Shortcuts automation "When I leave Home"   (POST /api/leaving)
#          @arrive      phone's "When I arrive Home"                       (POST /api/arrived)
#          @walk-away   band's signal to the home Mac faded (fallback for leaving)
#          @lock-sound  band mic heard YOUR calibrated lock sound
#          @twist       band felt a key-turn wrist twist
#          @click       band mic heard a click-ish sound (counts together with a twist)
#          @tick        only move the clock so timed rules can fire
# Times move the server's demo clock; the real clock is untouched.
